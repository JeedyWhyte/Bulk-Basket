# Design Assets

This folder contains all design assets for BulkBasket.

## Contents

| Folder | Contents |
|--------|----------|
| `figma/` | Figma design file exports and links |
| `assets/` | App icons, logos, illustrations |
| `brand/` | Brand guidelines, color palette, typography |
| `mockups/` | Screen mockups for all three user roles |

## Brand Colors

| Name | Hex | Usage |
|------|-----|-------|
| Primary Green | `#16A34A` | Buttons, primary actions |
| Dark Green | `#15803D` | Hover states |
| Orange | `#F97316` | Secondary accent |
| Neutral 900 | `#171717` | Body text (dark mode) |
| Neutral 50 | `#FAFAFA` | Background (light mode) |
